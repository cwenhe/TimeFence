# 时界（TimeFence）

时界是一款完全在设备本地运行的 Android 应用。你可以选择应用、时间范围和每周重复日期；规则开始时，即使目标应用已经停留在前台且没有产生新的窗口切换，时界也会主动检查并将它送回桌面。

> 普通 Android 应用不能直接结束其他应用的进程。时界通过无障碍服务执行系统“返回桌面”操作，并在规则有效期间持续拦截再次进入的目标应用。

## 功能

- 按开始时间、结束时间和星期设置重复规则。
- 一条规则可限制多个具有桌面入口的应用。
- 同时监听窗口变化，并在规则时间边界主动检查前台应用。
- 支持跨午夜规则，例如 `22:00-07:00`。
- 重启、日期、时间或时区变化后重新计算下一次边界。
- 所有规则仅保存在本机，不需要账号、网络或云端同步。
- 针对荣耀 MagicOS 提供自启动、后台运行和电池优化设置说明。

## 系统要求

- Android 8.0（API 26）及以上。
- Android 12 及以上建议授予“闹钟和提醒”权限，以便在时间边界准时主动检查。
- 必须开启时界的无障碍服务，才能识别前台应用并执行返回桌面。
- Android 13 及以上从 GitHub 侧载后，可能需要先在应用信息页选择“允许受限设置”，才能开启无障碍服务。

## 安装与首次设置

1. 从仓库的 GitHub Releases 页面下载 `timefence-<版本号>.apk`。
2. 对照同一 Release 中的 `.sha256` 文件校验 APK，然后在手机上安装。
3. 打开时界，按设置页提示开启无障碍服务。
4. Android 12 及以上开启“闹钟和提醒”权限。
5. 在荣耀设备上继续完成[荣耀 MagicOS 设置](docs/honor-setup.md)。
6. 创建一条两分钟后开始的短规则，提前打开目标应用并保持不操作，确认到点后能自动返回桌面。

Android 13 及以上如果系统拒绝开启侧载应用的无障碍服务，请打开“设置 -> 应用 -> 时界 -> 右上角菜单 -> 允许受限设置”，再返回无障碍设置重试。不同系统版本的名称可能略有差异。

## 使用限制

- 用户强制停止或卸载时界、关闭无障碍服务，或系统撤销权限后，保护无法继续。
- 厂商后台策略可能延迟闹钟或终止应用进程；设置页会尽可能反映权限状态，但无法绕过系统限制。
- 画中画、分屏和锁定任务模式由系统或目标应用控制，首版不承诺与普通全屏场景完全一致。
- “生效期间锁定本规则”只限制在时界内修改规则，不能阻止用户更改系统设置或卸载应用。

更多排查信息见[诊断指南](docs/diagnostics.md)。

## 本地构建

准备 JDK 17、Android SDK Platform 35 和 Android Build Tools 35.0.0，然后运行：

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug
```

Debug APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。发布版必须使用长期保存的签名密钥，配置方法见[发版指南](docs/release-guide.md)。

## 隐私

时界不申请网络权限，不上传规则或使用记录。无障碍服务只用于识别当前应用和执行返回桌面，不读取或保存页面文字、键盘输入、账号信息或屏幕内容。诊断日志仅包含规则标识、应用包名、时间边界和权限状态。

# 时界（TimeFence）

时界是一款以本地规则为核心的 Android 应用。你可以选择应用、时间范围和每周、法定工作日或 A 股交易日；规则开始时，即使目标应用已经停留在前台且没有产生新的窗口切换，时界也会主动执行限制。

> 默认模式通过无障碍服务执行系统“返回桌面”操作。可选的 Shizuku 系统暂停模式会停止目标应用已有界面并拒绝再次启动；该模式需要单独安装、启动并授权 Shizuku。

## 功能

- 按开始时间、结束时间和星期设置重复规则。
- 支持中国法定工作日（含调休）和沪深交易所共同交易日，并缓存联网更新的公开日历。
- 一条规则可限制多个具有桌面入口的应用。
- 同时监听窗口变化，并在规则时间边界主动检查前台应用。
- 可选 Shizuku 系统暂停模式，使规则内应用无法再次启动；服务异常时保留无障碍兜底。
- 关键系统包保护、暂停责任记录和一键解除全部暂停。
- 合并小窗和分屏产生的高频窗口事件，避免窗口数量拖慢到点拦截。
- 支持跨午夜规则，例如 `22:00-07:00`。
- 每条规则可以自定义浮层和通知文本，并选择是否由系统 TTS 朗读。
- 重启、日期、时间或时区变化后重新计算下一次边界。
- 所有规则和提示文本仅保存在本机，不需要账号或云端同步；网络只用于下载公开日历。
- 针对荣耀 MagicOS 提供自启动、后台运行和电池优化设置说明。

## 系统要求

- Android 8.0（API 26）及以上。
- Android 12 及以上建议授予“闹钟和提醒”权限，以便在时间边界准时主动检查。
- 必须开启时界的无障碍服务，才能识别前台应用并执行返回桌面。
- 系统暂停模式为可选高级能力，需要 Shizuku 11 及以上；Android 11 及以上非 Root 设备通常可在手机端通过无线调试启动，Android 10 及以下需要电脑 ADB。
- Android 13 及以上从 GitHub 侧载后，可能需要先在应用信息页选择“允许受限设置”，才能开启无障碍服务。

## 安装与首次设置

1. 从仓库的 GitHub Releases 页面下载 `timefence-<版本号>.apk`。
2. 对照同一 Release 中的 `.sha256` 文件校验 APK，然后在手机上安装。
3. 打开时界，按设置页提示开启无障碍服务。
4. Android 12 及以上开启“闹钟和提醒”权限。
5. 在荣耀设备上继续完成[荣耀 MagicOS 设置](docs/honor-setup.md)。
6. 创建一条两分钟后开始的短规则，提前打开目标应用并保持不操作，确认到点后能自动返回桌面。
7. 需要“点都点不开”的效果时，安装并启动 Shizuku，在时界“设置 -> 高级拦截”中授权并启用系统暂停模式。

Android 13 及以上如果系统拒绝开启侧载应用的无障碍服务，请打开“设置 -> 应用 -> 时界 -> 右上角菜单 -> 允许受限设置”，再返回无障碍设置重试。不同系统版本的名称可能略有差异。

## 使用限制

- 用户强制停止或卸载时界、关闭无障碍服务，或系统撤销权限后，保护无法继续。
- 非 Root Shizuku 通常会在手机重启后停止，而应用暂停状态可能继续保留；重新启动 Shizuku 后时界会自动校正，也可以使用“解除全部暂停”。
- Shizuku 不可用时，时界不会开始新的系统暂停，但仍保留无障碍拦截。普通应用无法自动完成无线调试配对或跨重启永久启动 Shizuku。
- 厂商后台策略可能延迟闹钟或终止应用进程；设置页会尽可能反映权限状态，但无法绕过系统限制。
- 工作日和交易日只在已发布日历覆盖范围内生效；截至 2026 年 8 月，2027 年官方安排尚未发布，应用不会用普通星期规则猜测未知日期。
- 画中画、分屏和锁定任务模式由系统或目标应用控制，首版不承诺与普通全屏场景完全一致。
- “生效期间锁定本规则”只限制在时界内修改规则，不能阻止用户更改系统设置或卸载应用。

更多排查信息见[诊断指南](docs/diagnostics.md)。

## 本地构建

准备 JDK 17、Android SDK Platform 35 和 Android Build Tools 35.0.0，然后运行：

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug
```

Debug APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。发布版必须使用长期保存的签名密钥，配置方法见[发版指南](docs/release-guide.md)。

## 隐私

时界只使用网络权限从本项目固定 HTTPS 地址更新公开的工作日和交易日日历，不上传规则、包名、提示文本或使用记录。无障碍服务只用于识别当前应用和执行返回桌面，不读取或保存页面文字、键盘输入、账号信息或屏幕内容。诊断日志仅包含规则标识、应用包名、时间边界、日历版本和权限状态。

启用系统暂停模式后，包名会通过仅限本机 Binder 连接交给 Shizuku UserService 执行系统包管理命令，不会发送到网络。时界只恢复本地记录为自己管理的包；其他 Shizuku 工具同时修改同一应用时，Android 不提供跨工具的绝对所有权隔离。

启用语音播报后，提示文本会交给设备的系统 TTS 引擎。部分厂商 TTS 引擎可能自行联网处理语音，具体行为由用户选择的系统引擎及其隐私政策决定；时界本身不会把提示文本发送到自己的服务器。

# 荣耀 MagicOS 设置

荣耀设备的后台管理可能延迟精确闹钟或清理时界进程。首次安装、系统升级或发现到点未拦截时，请重新核对本页设置。

> MagicOS 版本、机型和地区不同，菜单名称与入口可能变化。优先使用时界设置页提供的系统入口；找不到时，可在系统设置中搜索本页列出的关键词。

## 1. 允许无障碍服务

1. 打开时界的“设置”页面，进入无障碍设置。
2. 在“已下载的应用”或“已安装的服务”中找到“时界”。
3. 开启服务并确认系统警告。

Android 13 及以上侧载 APK 如果显示“出于安全考虑，此设置目前不可用”：

1. 打开“设置 -> 应用 -> 应用管理 -> 时界”。
2. 打开右上角菜单，选择“允许受限设置”。
3. 返回无障碍设置并重新开启时界。

该选项只应对你确认来源可信的 APK 开启。正式版本应从本项目 GitHub Releases 下载，并校验 SHA-256。

## 2. 允许闹钟和提醒

Android 12 及以上在时界设置页进入“闹钟和提醒”，允许时界安排精确闹钟。该权限用于处理规则开始前已经停留在前台的应用。

如果拒绝，窗口切换时的拦截仍可能工作，但时间边界主动检查可能被系统延迟。

## 3. 允许应用启动和后台活动

在系统设置中搜索“应用启动管理”或“应用启动”，找到时界后关闭自动管理，并允许可见的相关选项，例如：

- 允许自启动。
- 允许关联启动。
- 允许后台活动。

部分 MagicOS 版本的入口位于“设置 -> 应用 -> 应用启动管理”，也可能位于电池设置中。只需调整时界，不需要放宽其他应用的设置。

## 4. 调整电池优化

1. 从时界设置页打开电池优化页面，或在系统设置中搜索“电池优化”。
2. 切换到“所有应用”，找到时界。
3. 选择“不允许优化”“不限制”或系统版本中含义相同的选项。

这会增加时界在后台准时运行的机会，也可能带来少量额外耗电。

## 5. 检查通知权限

Android 13 及以上建议允许通知，以便看到保护状态和权限异常。拒绝通知不会直接关闭核心拦截，但排查后台问题会更困难。

## 6. 可选：配置 Shizuku 系统暂停

需要让目标应用在规则内完全无法启动时，可以安装 Shizuku 并在时界“设置 -> 高级拦截”中授权。MagicOS 基于 Android 11 及以上时，非 Root 设备通常可以直接在手机上通过开发者选项的无线调试完成配对和启动；较旧系统需要电脑 ADB。

非 Root 手机每次重启后通常需要重新启动 Shizuku。目标应用的暂停状态可能跨重启保留，因此不要卸载时界；先启动 Shizuku，等待时界自动校正，必要时点击“解除全部暂停”。桌面、设置、电话、输入法、安装器、Shizuku 和时界本身不会进入暂停目标。

## 7. 执行到点验收

1. 创建一条两分钟后开始、持续两分钟的规则。
2. 选择一个普通第三方应用作为目标。
3. 在开始时间前打开目标应用，并保持屏幕点亮且不触摸。
4. 确认开始时间到达后约一秒内返回桌面。
5. 在规则生效期间再次打开目标应用，确认再次返回桌面。
6. 等规则结束后确认目标应用恢复可用。

启用系统暂停模式后，再确认规则开始时目标应用已有界面被停止，规则内从桌面点击也不能进入；规则结束后可以正常启动。

再分别验证锁屏跨过开始时间、手机重启、修改时区和系统省电模式。画中画、分屏和锁定任务模式需要单独记录结果。

## 仍然失效时

先确认时界没有被强制停止，无障碍服务仍显示已连接，并查看首页显示的下一条边界。随后按[诊断指南](diagnostics.md)记录系统版本、权限状态、规则时间和复现步骤。
